# Trance v1.2.0

Based on SpectralPack/Trance at 3f86c2e (the parent has no newer commits as of this release).

## Fixed
- The **Trance** button is back in the options (pause) menu during a run and from the main menu. The parent only added it when Steamodded was not loaded, so with Steamodded it never appeared. It is now always added.
- The button is added after the stock buttons, so Settings, New Run, Main Menu, Mods, Stats, Collection, Customize and any buttons from other mods keep their order. It is only added once, and if anything unexpected happens the stock options menu is left untouched.
- The Trance screen opened from that button now builds its tab correctly (the tab was handed over as a finished table instead of a function).

## Added
- New palette: **Third Street Saints**.

## Install
Download `Trance-v1.2.0.zip`, extract it into `%AppData%\Balatro\Mods\` so you end up with `Mods\Trance\trance.lua`. Requires Lovely. Steamodded is optional.
