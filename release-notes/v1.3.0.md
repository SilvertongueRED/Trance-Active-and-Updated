# Trance v1.3.0

The parent repository (SpectralPack/Trance) was archived on Aug 24, 2026, so its two open pull requests can no longer be merged there. This release pulls both into the fork with their original authorship kept.

## Added
- Palette **OLED Friendly** (parent PR #10 by Chris Riker): blacks out the chips and mult score boxes and the options button.
- Font **League Gothic** (parent PR #11 by jack5github). League Gothic is licensed under the SIL Open Font License 1.1.

## Notes
- Both additions are new files only, so nothing existing is changed. Pick them in the Trance screen under Selected Palette and Selected Font.
- Both files load as valid Lua. I have not yet looked at either in game.

## Install
Download `Trance-v1.3.0.zip`, extract it into `%AppData%\Balatro\Mods\` so you end up with `Mods\Trance\trance.lua`. Requires Lovely. Steamodded is optional.
