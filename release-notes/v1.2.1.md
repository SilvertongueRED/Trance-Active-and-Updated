# Trance v1.2.1

## Fixed
- The **Trance** button in the options (pause) menu is now a compact button. With many mods installed the options menu is already tall, and the full size button pushed the top of the menu (Settings) and the Back button off screen.

## Unchanged
- The button is still added once, after the stock buttons, and the stock menu is left alone if anything goes wrong.

## Install
Download `Trance-v1.2.1.zip`, extract it into `%AppData%\Balatro\Mods\` so you end up with `Mods\Trance\trance.lua`. Requires Lovely. Steamodded is optional.
